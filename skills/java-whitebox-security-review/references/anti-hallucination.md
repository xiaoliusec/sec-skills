# Anti Hallucination

本文件定义审计中的强制约束，避免误报和编造。

## 强制规则

1. 文件必须真实存在，且已读取
2. 代码片段必须来自真实读取结果
3. 路由、函数、配置项必须能落到具体位置
4. 调用链的每一跳都应可解释
5. 无法确认时必须标记为 `suspicious` 或 `probable`
6. 宁可漏报，不可误报
7. 不得根据“典型项目结构”直接推断漏洞成立

## 常见误报来源

- 只看到危险 API，未看到参数可控性
- 只看到缺少注解，未看到 service 层控制
- 只看到字符串拼接，未确认是否进入执行点
- 只看到配置项，未确认实际生效环境
