# Methodology

本 skill 采用防御性白盒安全审计方法论。

## 方法核心

1. 先识别框架和项目边界
2. 先梳理入口点，再分析危险汇点
3. 同时使用 sink-driven 与 control-driven 两条轨道
4. 先确认风险链路，再输出结论
5. 先给修复建议，再讨论扩展风险

## 双轨模型

### Sink-driven

适用于：

- SQL 注入
- 命令执行
- SSRF
- 文件读写
- 反序列化
- 表达式执行

执行方式：

1. 找危险 API
2. 追踪参数来源
3. 检查中间传播
4. 检查是否存在防护
5. 判断风险是否成立

### Control-driven

适用于：

- 认证缺失
- 授权缺失
- 水平越权
- 垂直越权
- 资源归属校验缺失
- 业务敏感操作保护不足

执行方式：

1. 列出路由和入口
2. 标识敏感操作
3. 检查认证与权限控制
4. 检查资源归属与租户边界
5. 判断是否存在“应有而无”的安全控制

## 审计优先级

优先审计：

- 登录、用户、角色、权限
- 管理后台
- 订单、支付、审批、导出
- 文件上传、下载、预览
- 外部请求、回调、抓取
- 动态 SQL、动态模板、动态表达式
