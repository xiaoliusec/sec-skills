# Java Sources And Sinks

## 常见 Source

- `@RequestParam`
- `@PathVariable`
- `@RequestBody`
- `HttpServletRequest`
- Header / Cookie
- `MultipartFile`
- MQ 消息

## 常见 Sink

- JDBC 执行
- MyBatis 动态 SQL
- `Runtime.getRuntime().exec`
- `ProcessBuilder`
- 文件系统读写
- 模板渲染
- 出站 HTTP 请求
- 反序列化入口

## 常见 Control

- `@Validated` / `@Valid`
- 参数化查询
- 白名单校验
- 资源归属校验
- 路径归一化
- 上传类型校验
- 协议/域名/IP 白名单
